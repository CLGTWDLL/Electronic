# motion-v3 K230相机部署

本脚本按 `DEPLOY_NOTES.md` 中确认的模型接口编写：

- 输入：`[1,3,416,416]`、RGB、NCHW、外部float32、除以255
- 相机AI源：完整`640×640`
- 输出：`[1,10647,6]`
- 分数：`objectness × Steel_Ball_probability`
- 坐标：416 letterbox `xywh`，还原比例为`20/13`
- 后处理：阈值筛选、`xywh→xyxy`、完整NMS

## SD卡布局

```text
/sdcard/
├── main.py
└── mp_deployment_yolov8/
    ├── k230_deploy_config.json
    ├── labels.txt
    └── steel_ball_416_motion_v3_nncase_2.9.0.kmodel
```

把 `k230_camera_track_motion_v3.py` 复制为 `/sdcard/main.py`。

## 速度设计

- 显式执行AI2D的`640×640→416×416`缩放，AI2D输出保持`uint8`。
- 在AI2D之后使用`resized_input / 255.0`生成模型浮点输入，不调用
  CanMV v1.4.3不支持的`astype()`。
- 使用固件支持的`np.compress`批量筛选10647行。
- 不执行阻塞式旧帧丢弃。
- 每30帧才执行一次垃圾回收。
- 每120帧才打印一次性能日志。
- OSD每帧只绘制检测框和一条状态文字。

正常首帧日志应包含：

```text
First input shape: (1, 3, 416, 416)
First input dtype: float32
First input min/max: 0.0 1.0
First output shape: (1, 10647, 6)
Fast candidate filter: np.compress
```

部分固件会省略batch维并显示`(3,416,416)`，脚本也已兼容。
