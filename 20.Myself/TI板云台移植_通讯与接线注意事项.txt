TI板云台移植：通讯与接线注意事项

一、基本要求
1. TI板至少需要两路独立UART：
   - Camera_UART：接K230相机。
   - Motor_UART：接F32C云台。
2. 两路UART均为115200、8位数据、1位停止位、无校验、无流控（115200 8N1）。
3. TI引脚可自行选择，不要照抄STM32引脚号；原程序中USART1/PC4-PC5接电机，USART2/PA2-PA3接相机。
4. 所有设备必须共地。UART为3.3V TTL，不是RS232/RS485；若TI板IO电平不兼容，必须加电平转换。

二、K230相机接线
K230 IO9（TX）  -> TI Camera_UART_RX
K230 IO10（RX） <- TI Camera_UART_TX（当前程序不需要，可不接）
K230 GND         -> TI GND
K230 5V          -> 稳定5V电源

注意：
1. 当前相机只向TI发送数据，所以IO9、Camera_UART_RX和共地是通信必需连接。
2. 5V只能接相机电源脚，不能接TI的UART IO。
3. 5V电源要有足够电流；不要同时使用两个5V电源给相机反向供电。

三、相机通讯协议
ASCII帧，无校验和，无换行要求：

$length,14,x,y,w,h,Steel_ball#

字段说明：
- length：整帧总字节数，包含“$”和“#”。
- 14：固定功能号。
- x、y：检测框左上角坐标。
- w、h：检测框宽和高。
- Steel_ball：固定类别名，大小写必须完全一致。
- 坐标系固定为1280×720；TI端用(x+w/2, y+h/2)作为钢球中心。

接收要求：
1. 收到“$”开始收帧，收到“#”结束。
2. 校验length、功能号14、类别名、坐标范围和框尺寸。
3. 字符串不完整、超长或超过300ms未收到有效目标时，按目标丢失处理。

四、F32C云台接线
TI Motor_UART_TX -> 云台UART RX
TI Motor_UART_RX <- 云台UART TX
TI GND           -> 云台通信GND

1号、2号电机共用同一路UART总线，地址分别为0x01、0x02。保持云台原有串接/总线接法，不要把两个不支持并联的推挽TX强行短接。

云台电机使用独立的额定电源供电，不能由TI板3.3V或5V脚直接供电；电机电源地、TI地和相机地必须相连。

五、电机通讯协议
发送帧：

7A  ID  FUNC  [DATA]  BCC  7B

- ID：1号电机=01，2号电机=02。
- BCC：从7A到最后一个DATA逐字节异或。
- 多字节数据使用大端序，高字节在前。

当前程序常用功能码：
- 06：使能电机。
- 05：关闭电机。
- 00 00 00：设置速度模式。
- 01 speed_H speed_L：设置速度，speed为有符号int16，单位RPM。
- 0E 01：请求多圈角度。
- 0A：把当前位置保存为单圈绝对角度零点，仅标定时使用。

电机反馈固定9字节：

7A  ID  TYPE  DATA3 DATA2 DATA1 DATA0  BCC  7B

- TYPE=01：多圈角度反馈。
- 角度为有符号int32大端数，单位0.1°。
- 必须检查帧头、帧尾、ID和BCC。

六、移植时必须保留
1. Camera_UART和Motor_UART的接收中断或DMA持续工作。
2. 两台电机共享UART时，所有发送必须统一排队，禁止两段代码同时发送。
3. 不要在高优先级中断里阻塞发送电机帧或延时。
4. 保留目标300ms超时、电机反馈100ms超时和超时零速保护。
5. 上电先等待相机和电机电源稳定；建议至少等待500ms，再依次使能两台电机并设置速度模式。
6. 电机命令之间保留间隔；冷启动不稳定时将间隔增大到50～200ms。
7. 不要改动电机地址、转向、零点和控制参数，除非在实物上重新确认。

七、首次测试顺序
1. 不给电机使能，先确认TI能连续收到相机ASCII帧。
2. 只接一个电机，验证使能、速度0和多圈角度反馈。
3. 再接第二个电机，确认地址01、02反馈不会混淆。
4. 架空云台，以低速度测试两个方向。
5. 最后开启视觉追踪，并测试相机断线后电机能否及时停转。
