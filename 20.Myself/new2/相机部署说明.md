# steel_ball_416 相机部署

本脚本严格按 `DEPLOY_NOTES.md` 中已经确认的接口编写：

- 模型输入：RGB、NCHW、外部 `float32`、除以 `255.0`
- 输入 shape：`[1, 3, 416, 416]`
- 输出 shape：`[1, 10647, 6]`
- 最终分数：`objectness × Steel_Ball_probability`
- 后处理：`xywh` 转 `xyxy` 后执行 NMS

## SD 卡文件布局

将以下三个文件放入：

```text
/sdcard/mp_deployment_416/
    k230_deploy_config.json
    labels.txt
    steel_ball_416_nncase_2.9.0.kmodel
```

将 `k230_camera_detect_416.py` 复制到 SD 卡根目录并改名为：

```text
/sdcard/main.py
```

## 设计说明

相机 AI 帧保持 `640×640`，模型输入为 `416×416`。两者宽高比相同，
因此预处理只进行双线性缩放，不产生 padding，等价于部署说明规定的
letterbox，且避免不同 CanMV 固件中 AI2D padding/resize 顺序造成差异。

脚本没有丢弃相机帧。候选框使用当前固件支持的 `np.compress` 批量筛选，
之后执行完整 NMS。垃圾回收每 15 帧执行一次。

首次运行会检查实际输入、输出 shape，并打印输入数值范围。正常信息应包括：

```text
First model input shape: (1, 3, 416, 416)
First model input min/max: 0.0 1.0
First model output shape: (1, 10647, 6)
Vector candidate filter: np.compress
```

实际最小值和最大值可以略高于 `0.0` 或略低于 `1.0`。
部分固件的 AI2D wrapper 可能省略 batch 维并显示
`(3, 416, 416)`；脚本同时兼容这两种返回形式。
