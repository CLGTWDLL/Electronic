# 运动钢球数据采集

将 `capture_motion_dataset_640.py` 复制到 SD 卡根目录并改名为
`/sdcard/main.py`，重启相机。

脚本启动并完成约 3 秒自动曝光预热后：

1. 按一次可编程 USER 按键，开始连续采集。
2. 让钢球按实际使用速度经过画面不同区域。
3. 再按一次 USER 按键，结束当前采集段。
4. 改变运动方向、距离、光照或背景，再开始下一段。

不要按靠近 USB 接口的复位键。

图片保存在：

```text
/sdcard/motion_dataset_640/session_001/
/sdcard/motion_dataset_640/session_002/
...
```

每次开始采集都会新建一个 session。默认目标速度为每秒 8 张，
单个 session 最多 600 张。JPEG 写卡速度不足时，实际帧率可能低于
8 FPS，终端会每 20 张打印实测速度。

## 数据集划分

必须按完整 session 划分训练集、验证集和测试集。例如：

```text
session_001～008 -> train
session_009     -> val
session_010     -> test
```

不要把同一 session 的相邻帧随机拆到 train 和 val，否则验证结果会
虚高。

建议运动图片占正样本的约 30%～50%，同时保留原有静止、清晰钢球图片
和没有钢球的负样本。标注框应覆盖当前帧中实际可见的钢球及其运动拖影，
并在整个数据集中保持一致标注规则。
